# 词库数据目录

本目录的 `cet4.json` / `cet6.json` **不在 Git 仓库中**（已由 `.gitignore` 排除）。

## 为什么要自己生成

词书内容是有道考神 / 新东方的授权内容，版权归原作者所有。
仓库只提供生成脚本，不分发数据本身。

## 如何生成

在项目根目录依次执行：

```bash
node scripts/prepare-books.js    # 从网易官方 CDN 下载词书并解压为 JSONL
node build-wordbank.js           # 清洗去重，输出本目录的 cet4.json / cet6.json
```

生成结果：

| 文件 | 词数 | 说明 |
|---|---|---|
| `cet4.json` | 2000 | 四级（真题核心词占 56%） |
| `cet6.json` | 2541 | 六级（真题核心词占 26%） |

两者合计 4541 词，**全局零重复**，音标 / 释义 / 例句 100% 完整。

## 字段说明

| 字段 | 含义 |
|---|---|
| `word` | 单词 |
| `phonetic` | 英式音标（`/.../` 格式） |
| `meaning` | 中文释义（带词性，最多 2 个义项） |
| `example` / `exampleCn` | 例句与其中文翻译 |
| `example2` / `example2Cn` | 第二条例句 |
| `examExample` / `examSource` | 真题例句及其来源（如「2017.6 阅读理解」） |
| `rank` | 原始词书内的顺序（= 词频序） |
| `level` | `CET4` / `CET6` |
