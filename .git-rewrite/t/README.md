# 四六级 AI 批改

一个纯前端的大学英语四、六级备考工具。零后端、零配置、双击即用。

- **AI 作文批改** —— 按官方整体评分法（Holistic Scoring）给出 15 分制四维度评分
- **AI 翻译批改** —— 语义 / 要点 / 语法 / 中式直译 / 表达效果五维评估
- **AI 口语评分** —— 语音、词汇、语法、话题相关性、流利度五维
- **四级 / 六级词库** —— 4500+ 真题高频词，SM-2 间隔重复算法安排复习
- **错题本 / 打卡 streak** —— 学习进度本地保存，可选云端同步

## 快速开始

```bash
# 1. 安装依赖
npm install

# 2. 生成词库（首次必须，见下方「词库来源」）
node scripts/prepare-books.js
node build-wordbank.js

# 3. 构建单文件版
node build-standalone.js

# 4. 打开
#    方式一：双击 四六级AI批改.html
#    方式二：起个静态服务器
npx serve standalone-web
```

构建产物 `四六级AI批改.html` 是**完全自包含的单文件**（CSS / JS / 词库全部内联），
可以直接双击打开，也可以直接传到任意静态托管。

### 配置 AI 能力（可选）

AI 批改需要一把 `publishableKey`（决定谁能调用后端大模型）。
**本仓库不包含该凭据** —— 部署者需自行配置，二选一：

**方式一 · 浏览器控制台（最快，适合自用）**

```js
localStorage.setItem('wb.publishableKey', '你的 key')
```

**方式二 · 私有部署（构建时注入，适合自己托管）**

在项目根目录建 `.workbuddy/local-config.json`（该文件已被 `.gitignore` 排除）：

```json
{ "publishableKey": "你的 key" }
```

之后 `node build-standalone.js` 会自动把它注入产物。

> **未配置时的行为**：词库、背词、错题本、打卡等本地功能**完全可用**，
> 只有 AI 批改 / 翻译 / 口语评分会提示未配置。这样设计是为了让
> 开源版本不含任何他人可用的凭据。

## 在线体验

本项目有官方部署版本（功能完整），**但暂不公开访问地址**。

原因很直接：AI 批改每调用一次都是一次真实的大模型调用，
服务成本随使用量线性增长。公开地址等于把这份成本无限分摊给陌生人，
既不可持续，也会给项目带来不必要的风险。

**想用？自己部署是最省事也最可靠的方式** —— clone 之后按上面步骤跑起来，
AI 部分配上自己的 key 即可。这正是开源的意义：代码在这里，怎么用你决定。

**本仓库不包含词库数据。** 词库由脚本从官方来源生成：

> 使用承担任何责任。词书顺序即真题词频序，这是分级准确的基础。

词库分级口径：
- **四级** 2000 词（真��核心词占 56%）
- **六级** 2541 词（真题核心词占 26%）

## 评分标准

### 词数判定（完全本地计算，不依赖 AI）

判定只用**及格线**，黄金区仅作建议 —— 两者性质不同，混在一起判会出现歧义。

| 等级 | 及格区间 | 稳妥区间（仅提示） |
|---|---|---|
| 四级 | 120-180 词 | 140-170 词 |
| 六级 | 150-200 词 | 165-190 词 |

字数为达标时**不显示任何警告**；只有真正低于下限才提示差多少。
判定逻辑见 `web/js/grading-levels.js`。

### 翻译评分

四六级翻译**不按字数降档**，只看译文质量：语义准确、要点完整、语法正确、
中式直译规避、表达效果。原文长度影响的是「是否漏译」，在 `accuracy` 维度体现。

## 技术要点

**词库按需加载**：1.7MB 词库不能内联进代码，否则首屏明显卡顿。
采用四级 / 六级分片，gzip 后内联（浏览器原生 `DecompressionStream` 解压，
零第三方依赖），配合 localStorage 缓存。

**页面缓存与一致性**：首页 / 我的页结构稳定，走 DOM 缓存；
词汇 / 批改页交互即改数据，每次重绘。`persist()` 统一触发缓存失效，
保证「复习完单词回首页看到新进度」这类场景不显示旧数据。

**字数提示全部由代码生成**：AI 的评语是概率性的，字数判定交给本地计算，
100% 准确。提示词里明确要求 AI 不重复播报字数，避免与界面提示矛盾。
